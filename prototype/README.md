# OntoloHub 原型使用指南

## 启动方式

```
# 直接双击打开
prototype\index.html

# 或用浏览器
start prototype\index.html
```

打开后即可在浏览器中点击所有功能（单文件 HTML，无外部依赖）。

## 关键 PRD 约束在原型中的体现

> MVP 优先实现表格和属性表单，关系图提供查看、选中与定位。

→ **类树不是复杂图画布**，是树形列表（展开/折叠）。

> 候选类、属性、关系和映射均先进入 Proposal，不能直接写入已发布版本。

→ **接受/拒绝队列** + 不在类树直接编辑。

> 100% 已发布定义和关键映射有证据或人工确认。

→ **驾驶舱**底部"M1 退出条件"显式跟踪这条。

> M1 仅 3 个验收查询匹配。

→ **映射与验证**列出 3 条验收查询。
